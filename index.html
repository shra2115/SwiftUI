    API and API key
    

    API used: dummyjson.com/products (free, no key needed, has images, price, rating, discount). If the interviewer gives a key (Google or other), paste it in Config.swift. Two common styles are handled in the code: a header key, or a ?key= query parameter (Google style).
    

    Xcode setup: New Project, iOS App, Interface SwiftUI. Add the files below, run. If the API is plain http, add an ATS exception in Info.plist; https needs nothing.
